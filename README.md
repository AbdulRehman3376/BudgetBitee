# BudgetBite

Budget-aware food discovery and meal planning.

## Project location
D:\Projects\MobileDev\BudgetBite

## Planned stack
- Backend: Python, FastAPI
- Database: SQLite for local development
- Frontend: dedicated frontend application
- Testing: Python unittest initially

## Core scope
- User-defined food budgets
- Restaurant and dish catalogue
- Budget-based meal planning
- Expense tracking
- Meal-plan history
- Administrative management
- Input validation and error handling

## Development rules

- Never commit credentials or real secrets.
- Use sample data clearly labelled as sample data.
- Verify features with tests before claiming they work.
- Back up database files before destructive migrations.
